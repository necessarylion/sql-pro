# Security policy

## Supported versions

Only the latest release gets security fixes. Please update to the latest release first.

## Report a vulnerability

Please report it in private. Do not open a public issue.

1. Go to https://github.com/necessarylion/sql-pro/security/advisories/new
2. Click "Report a vulnerability" and describe the problem.
3. Add the steps to repeat it, the version you used, and your operating system.

## What to expect

SQL Pro has one maintainer, so this is best effort.

- You get a first reply within 7 days.
- If the report is valid, a fix is made and released as soon as possible.
- You are credited in the release notes, unless you prefer not to be.
